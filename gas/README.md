# 親機の表の共有（Googleドライブ＋GAS）の準備

管理者が「親機の表」をGoogleドライブに送り、子機のタブレットがネットにつながったときに受け取るしくみです。
子機で自分で入れた表（端末だけの表）は消えません。照合そのものは、これまでどおりネットなしで動きます。

## 1. GASを作る（最初の1回だけ・管理者のGoogleアカウントで）
1. https://script.google.com/ を開き、「新しいプロジェクト」を押す
2. 最初から入っている文字を全部消して、このフォルダの `Code.gs` の中身を全部貼り付ける
   （GitHub：https://github.com/overbridge038-lnk/point-shogo/blob/main/gas/Code.gs の「Raw」から全部コピー）
3. 上の2行を書き換えて保存（💾）
   - `READ_KEY` … 閲覧の合言葉（子機に入れる）
   - `SEND_KEY` … 送信の合言葉（管理者だけが知る）
   - 推測されにくいもの（10文字以上、英数字まぜる）にしてください。2つは別のものに
4. 右上の「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（合言葉で守ります。Googleにログインしていないタブレットからも使えるようにするため）
5. 「デプロイ」→ 権限の確認（「詳細」→「（安全ではないページ）に移動」→「許可」）
6. 出てきた **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

データは、マイドライブの「ポイント照合ツール_親機データ」フォルダに自動で入ります（中身は直接さわらないでください）。

## 2. タブレットに入れる
設定タブ →「親機の表の共有（Googleドライブ）」
- 「GASのURL」に上のURL、「閲覧の合言葉」に READ_KEY を入れる（どちらも入れた時点で保存）
- 「ポイント表の受け渡し」で「⚙ 設定も入れる」にして一式ファイルを渡すと、URLと閲覧の合言葉も一緒に入ります

## 3. 使いかた
- 管理者（親機）：表をそろえて、「管理者用：親機の表として送る」に送信の合言葉を入れて「📤 送る」。版が1つ上がります
  - この端末の表**すべて**が親機の表になります。入れたくない表は先に消してください
- 子機：ネットにつながると自動で受け取ります（起動時・10分ごと。照合の途中やNGの間は待ちます）。「🔄 今すぐ確認して受け取る」でも受け取れます
- 画面の上に「親機 第◯版」が出ます。全台が同じ版か、ひと目で確かめられます
- 照合の記録（CSV）の最後の列に、使った親機の表の版が残ります（端末だけの表なら「端末だけ」）

## Code.gs を直したとき
「デプロイ」→「デプロイを管理」→ 鉛筆 →「バージョン：新しいバージョン」→「デプロイ」。URLは変わりません。
合言葉を変えたときも同じ手順で反映し、タブレット側の合言葉も入れ直してください。

## 注意
- 本物の合言葉を書いた Code.gs は、GitHub（公開）に上げないでください
- 動画も送ると時間がかかります（3MBずつ送ります）
